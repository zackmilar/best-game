# Starfall Keep

An arena wave survival game for the [make.fun best-game-01 bounty](https://make.fun/bounty/best-game-01).

WASD/arrows to move, mouse to aim, auto-fire, dash with Space or right-click. Survive 5 waves, draft 1 of 3 blessings between waves, and defeat the Hollow Star boss on wave 5. Combo multiplier up to x5, golden motes, juice and WebAudio synth — plain ES modules, no engine, no network.

Run: `MAKEFUN_OUTPUT_DIR=out node main.ts` builds the dossier; `node serve.ts` serves the game locally.
